
🎙️ Voice Calculator 

Voice Calculator is a simple, interactive, and user-friendly mobile application designed to make mathematical calculations easier through voice input. Instead of manually typing numbers and mathematical operators, users can simply press the “Speak” button and say their calculation. The application uses speech recognition to capture the user's voice, displays the recognized expression under “Heard”, processes the calculation, and displays the final answer under “Result.”

The application was developed using MIT App Inventor, making use of its visual block-based programming environment. The project demonstrates how mobile applications can combine voice recognition, user interface components, and mathematical logic to create a practical and interactive tool.

✨ Key Features

🎤 Voice-Based Input – Users can speak mathematical expressions instead of typing them.

👂 Speech Recognition – The application captures and recognizes the user's spoken input.

📝 Heard Display – The recognized voice input is displayed so the user can see what the application understood.

🧮 Mathematical Calculation – The application processes the recognized expression and produces the corresponding result.

⚡ Quick Interaction – Users can perform calculations with minimal interaction.

📱 Simple Interface – A clean interface makes the application easy to understand and use.

🔄 Interactive Processing – The app follows a simple flow from voice input to calculation and result.


🔧 How It Works

The working process of the application can be represented as:

Press Speak → Give Voice Command → Speech Recognition → Display Heard Text → Process Calculation → Display Result

For example, a user can provide a mathematical expression through voice. The application recognizes the speech, shows the recognized input, performs the required calculation, and presents the answer on the screen.

🎯 Objective

The main objective of Voice Calculator is to demonstrate the practical use of voice recognition technology in mobile application development while creating a useful calculator application. It also provides hands-free interaction and shows how simple programming concepts can be combined with modern input methods.
